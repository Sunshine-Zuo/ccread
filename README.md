# 静读

Android 本地电子书阅读器，纯 AI 完成。无网络、无账号、无广告，只读手机本地的 TXT / EPUB。

## 功能

- **导入**：通过系统文件选择器导入 TXT / EPUB，也支持从其他应用“打开方式”直接打开；微信等只提供临时授权的文件会自动复制到应用私有目录，之后仍可正常阅读。
- **书架**：三列书册式封面，显示书名、格式与阅读进度；最近阅读优先；长按可查看详情或删除。
- **TXT**：自动识别 UTF-8 / UTF-16 / GB18030 编码；自动分章并生成目录，可重新识别；段落首行缩进两个汉字。
- **TXT 翻页**：左右翻页支持点击和滑动，当前页与下一页沿手指方向同向移动；也可切换为上下滚动。
- **EPUB**：保留书籍自带的目录层级；支持图片全屏查看；字号、背景与左右留白可调，字号显示与 TXT 一致。
- **阅读设置**：字号、左右边距、行距、字体颜色、背景、翻页模式与亮度；字体色与背景色预置一一对应，也可用大圆盘自定义取色。
- **进度**：按 TXT 字符位置 / EPUB 定位符记录，再次打开自动回到上次位置。
- **界面**：古册风、宣纸 / 墨色 / 朱砂；阅读菜单贴住屏幕底边，支持上一章 / 下一章；菜单与面板跟随纸色切换明暗。
- **文件管理**：详情可查看格式、大小与文件位置，外部文件可跳转到所在系统目录；删除时可选择同时删除原文件；文件失效可重新选择关联。
- **隐私**：不申请网络权限，不登录、不统计、不上传；书架与阅读进度只保存在本机。

## 开发

- Kotlin + Jetpack Compose + Room + DataStore + Readium Kotlin Toolkit
- 支持 Android 8.0（API 26）及以上
- 构建：`./gradlew assembleDebug`，产物会复制到 `apk/jingdu.apk`
- 测试：`./gradlew testDebugUnitTest`
